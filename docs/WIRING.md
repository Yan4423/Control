# 接线与接口

以当前Git版本中的 `Src/usart.c`、`Src/tim.c`、`Inc/main.h` 和 `Src/gpio.c` 为软件映射依据。物理排线朝向、颜色和转接线版本要以实际C板手册及实物照片复核；这里不以线色推断针号。

## 两个BTS7960驱动

| C板PWM口 | MCU/定时器 | 对应驱动端子 | 正油门 | 负油门 |
|---|---|---|---|---|
| C3 | PE13 / TIM1_CH3 | 左RPWM | 0–50% | 0 |
| C4 | PE14 / TIM1_CH4 | 左LPWM | 0 | 0–50% |
| C5 | PC6 / TIM8_CH1 | 右RPWM | 0 | 0–50% |
| C6 | PI6 / TIM8_CH2 | 右LPWM | 0–50% | 0 |

左右电机为镜像安装，因此电气极性相反。表中是程序输出，不保证未核对实物时的车辆运动方向。SA禁止/未解锁时四路都为0；C1/C2不参与本版电机驱动，C7未启用作电机输出。

| 电源/控制连接 | 驱动端 | 备注 |
|---|---|---|
| 12V功率正极，经独立合适的保险/断电装置 | 两块BTS7960的B+ | 电机供电；禁止接到MCU GPIO |
| 功率负极 | 两块BTS7960的B- | 与逻辑GND、C板GND共地 |
| 既有5V逻辑供电 | 每块VCC、R_EN、L_EN | 沿用现有模块接法；核对模块版本 |
| C板GND | 每块驱动GND | PWM测量也以同一GND为参考 |
| 各电机两根动力线 | 各自驱动的M+/M- | 电机电源与编码器供电分开辨识 |

电机、驱动和电源的电流规格、保险数值、连接器型号尚未在仓库中完整核实。接手时按实物额定值记录，不把历史试验里的12V/占空比直接当作长期负载能力证明。

## RF206S输入

- 既有W.BUS信号路径到C板 USART3_RX / PC11。保留现有接收机接口/转接路径；若更换为裸GPIO直连，先核对信号电平及是否需要反相。
- USART3：100000 baud、偶校验、2停止位；HAL设置为9 bits，包含8个数据位和1个校验位，即线上的8E2。
- USART3为RX模式；生成代码也配置了PC10为TX复用，但本程序不通过它发遥控命令。
- DMA1 Stream1 / Channel4，Normal，字节对齐；USART3与DMA中断参与接收。
- 接收机供电按接收机铭牌/原接线确认，GND共地。

| 用途 | 人类通道号（从1起） | 代码数组索引 | 本项目历史实测参考 |
|---|---|---|---|
| 左摇杆前后/油门 | CH3 | 2 | 约353 / 1024 / 1694 |
| 右摇杆左右/转向 | CH1 | 0 | 中位约1024；正方向需实物核验 |
| SA使能 | CH5 | 4 | 禁止小于等于1024；允许大于1024 |

历史SA高位出现过1694、1896，判定依靠阈值，不要求某一个固定高位数。新遥控器的通道映射、行程、反向、混控和Failsafe必须核对。

## USB转TTL仪表

C板接口丝印可能为 `UART1`，本项目实际使用 **USART6**，不是MCU的USART1。

| C板MCU信号 | USB转TTL | 用途 |
|---|---|---|
| PG14 / USART6_TX | RXD | 必需，接收仪表数据 |
| GND | GND | 必需，共地 |
| PG9 / USART6_RX | TXD | 可选；当前固件不接收PC控制命令 |

调试UART使用3.3V TTL逻辑，115200 8N1。USB转TTL的5V脚不要接到MCU信号脚；C板应按其规定供电。ST-Link和USB转TTL是两个不同的USB设备，烧录成功不代表串口已连接。

## 编码器

- 左A：PF0 / EXTI0；左B：PF1 / EXTI1；都为双边沿、无内部上下拉。
- 编码器VCC/GND按实际型号核对，A/B送到MCU前核验电压和输出类型；不能仅凭“编码器用5V供电”认定GPIO可直接承受其输出。
- 代码读取x4边沿计数和counts/s，没有标定RPM。右编码器没有默认软件映射或解码，即使线已接好也不会有右侧反馈。
- PF0/PF1对应的板载连接器具体朝向和转接线请在接手时附近照；不要把PWM的C编号当成通用8针I/O座的针号。
